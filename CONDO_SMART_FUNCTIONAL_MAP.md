# Condo_Smart - Mapa funcional rector

## Regla arquitectonica maestro-detalle
Para modulos maestro-detalle: Alta independiente -> Busqueda/Filtros -> Grid maestro -> Seleccion -> Gestion del registro -> Carga diferida de una sola seccion.

## GENERAL - navegacion principal
- Inicio / Portafolio
- Residentes
- Condominios / Inmuebles
- Dashboard
- Reportes
- Notificaciones
- Configuracion
- Soporte

Los ocho iconos de GENERAL deben ser extracciones exactas de assets/brand/Designer.png.

## INMUEBLES - dominio interno
- Condominios verticales
- Conjuntos horizontales
- Locales comerciales
- Plazas comerciales
- Bodegas
- Unidades / Espacios
- Areas Comunes
- Planos

Areas Comunes y Planos son funciones internas de Inmuebles y NO entradas del menu principal. Sus iconos tambien deben proceder exactamente de Designer.png.
