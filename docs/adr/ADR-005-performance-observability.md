# ADR-005 - Observabilidad de Performance

Estado: VALIDADO / EVOLUTIVO

## Contexto
El rendimiento real no debe evaluarse únicamente mediante percepción o pruebas artificiales.

## Decisión
Instrumentar telemetría y análisis de performance.

## Razón
Permitir optimización basada en evidencia.

## Consecuencias
La telemetría puede posteriormente alimentar reglas y agentes técnicos de IA.
