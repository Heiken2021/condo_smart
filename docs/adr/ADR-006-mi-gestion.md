# ADR-006 - Dashboard Mi Gestión

Estado: VALIDADO

## Contexto
Los administradores necesitan comprender rápidamente el portafolio bajo su responsabilidad.

## Decisión
Utilizar una única vista ejecutiva con alcance dinámico.

Root:
visión global.

Administradores locales:
sólo inmuebles asignados.

## Razón
Evitar dashboards independientes y mantener una única regla de alcance.

## Consecuencias
La visualización consume el ámbito autorizado. La visualización no decide el ámbito.
