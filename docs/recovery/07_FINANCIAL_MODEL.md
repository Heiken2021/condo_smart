# Condo_Smart - Modelo Financiero Conceptual

Estado: DECISIÓN APROBADA / EN EVOLUCIÓN

## Objetivo

El modelo financiero de Condo_Smart deberá permitir entender no solamente cuánto se cobra o cuánto se gasta, sino la capacidad de cada inmueble para mantener financieramente su operación en el tiempo.

## Concepto Rector: Sostenibilidad Financiera

La sostenibilidad financiera representa la capacidad presente y proyectada del inmueble para generar y recaudar recursos suficientes para cubrir:

- mantenimiento;
- servicios;
- necesidades operativas;
- obligaciones programadas;
- contingencias;
- reservas definidas por las reglas de negocio;

sin comprometer la continuidad financiera de su operación.

## Cadena Conceptual

Cuotas e ingresos exigibles
-> cobranza efectiva
-> disponibilidad de recursos
-> gastos operativos
-> mantenimiento y servicios
-> reservas y contingencias
-> capacidad financiera operativa
-> sostenibilidad financiera.

## Distinciones Importantes

Ocupación física, cobranza, liquidez y sostenibilidad financiera están relacionadas, pero no son equivalentes.

Un inmueble con alta ocupación puede presentar problemas financieros si su cobranza es insuficiente o si sus costes operativos exceden la capacidad económica disponible.

## Dimensiones Futuras

El modelo deberá permitir analizar:

- ingresos exigibles;
- ingresos cobrados;
- cartera vencida;
- gastos operativos;
- mantenimiento;
- servicios;
- presupuesto;
- reservas;
- contingencias;
- liquidez;
- desviaciones;
- tendencias.

## Pendiente

Las fórmulas definitivas, objetivos y umbrales se definirán cuando el modelo financiero transaccional disponga de suficiente madurez.

No deben inventarse umbrales únicamente para completar un dashboard.
